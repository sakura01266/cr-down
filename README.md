# Chromium 全发行版黄页站点介绍（GitHub Pages）

## 站点概述
本网站是一个**个人维护、GitHub Pages 静态部署、无商业化、无广告**的 **Chromium 内核浏览器发行版黄页**。

不同于只提供单一 Chromium 原版下载的工具站，本站定位为**全网 Chromium 衍生浏览器汇总索引页**，主打「一站式收录所有基于 Chromium 内核的浏览器发行版」。

站点无流量、无推广、无名气，属于圈内自用的**小众资源黄页**，仅做整理、归档、分类、提供官方直链，不打包、不篡改、不二次分发程序。

## 核心定位：Chromium 发行版百科黄页
所有基于 **Chromium 开源内核** 二次开发的浏览器，全部统一归类收录：
- 大厂官方商业发行版
- 开源社区维护发行版
- 个人开发者定制轻量发行版
- 隐私净化去谷歌发行版

做到**一个页面，查遍所有 Chromium 系浏览器**。

## 收录浏览器分类

### 1. 官方大厂 Chromium 发行版
主流商用、国民级 Chromium 内核浏览器：
- **Google Chrome**（谷歌官方标准版）
- **Microsoft Edge**（微软基于 Chromium 重构的新版 Edge）
- **Brave Browser**（隐私防护、去广告开源浏览器）

### 2. 社区开源纯净发行版
主打开源、透明、无捆绑、无后台上报：
- **Ungoogled Chromium**
  最热门的去谷歌化 Chromium，移除全部谷歌追踪、账号绑定、云端服务，保留完整内核能力。

### 3. 个人小众定制发行版
个人开发者独立编译、轻量特化版本（圈内小众精品）：
- **Hibbiki Chromium**
  知名个人编译版，主打极致优化、编译参数调优、性能更强、体积更精简，面向资深用户。
- 各类轻量精简版、无沙箱版、便携版、低配置适配版等个人构建发行版

## 站点功能特点
1. **纯黄页索引**
   只做分类介绍、特性说明、官方仓库/下载直链，不托管安装包，安全可靠无篡改。

2. **全品类覆盖**
   同时覆盖商业版、开源版、个人魔改版、隐私版、性能优化版，市面上绝大多数 Chromium 衍生浏览器全部收录。

3. **极简静态页面**
   GitHub Pages 纯静态部署，无后端、无日志、无采集、无弹窗、无广告、无追踪。

4. **版本与特性标注**
   对每一款发行版标注：适用场景、优缺点、内核特点、更新频率、适合人群，方便用户一键挑选。

5. **永久免费归档**
   小众浏览器极易断更、失效、链接失联，本站长期归档有效地址，解决小众发行版找不到下载渠道的问题。

## 各类型发行版适用场景

### 商业版（Chrome / Edge / Brave）
适合：普通日常用户、需要稳定更新、需要生态同步、需要官方售后与同步服务。

### Ungoogled 去谷歌版
适合：隐私爱好者、拒绝数据上报、国内无谷歌环境、纯本地浏览用户。

### Hibbiki 个人优化版
适合：追求性能、低延迟、精简体积、喜欢原版内核但想要编译优化的资深用户、测试用户。

## 站点优势
- **全网少见的全量 Chromium 黄页**：多数网站只做单一下载，本站做**汇总百科索引**
- 兼顾大众浏览器 + 极客小众个人发行版
- 全部跳转官方源，无毒、无捆绑、无魔改
- 页面极简干净，GitHub Pages 稳定秒开
- 专门拯救小众绝版、个人维护的 Chromium 发行版资源

## 站点不足
- 纯人工维护，新增小众发行版存在滞后
- 仅为索引黄页，不提供网盘加速、不提供离线包
- 无搜索功能，纯目录式浏览
- 非官方项目，仅为个人资源整理归档

## 总结
这是一个**独一无二的 Chromium 全系浏览器黄页静态站**。

它不做流量、不做推广，纯粹为了解决「Chromium 衍生浏览器太多、版本杂乱、小众版本难找、分不清区别」的痛点，把大厂浏览器、开源纯净版、个人优化版全部整合在一个页面内，是极客与开发者专属的小众实用索引站点。

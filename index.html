关于 Chromium 项目

Chromium 是一个由 Google 主导开发的自由开源网页浏览器项目。它是 Google Chrome 浏览器的基础，同时也被 Microsoft Edge、Opera、Brave、Vivaldi 等众多主流浏览器所采用。


  • 首次发布：2008 年 9 月
  • 核心引擎：Blink（渲染引擎）+ V8（JavaScript 引擎）
  • 开源协议：BSD 许可证（主要部分）
  • 衍生产品：Google Chrome、Microsoft Edge、Opera、Brave、Vivaldi 等

Linux

Linux

使用系统包管理器安装

选择对应的发行版和命令复制到终端执行：

Debian / Ubuntu / Linux Mint
sudo apt install chromium
Fedora / RHEL / CentOS
sudo dnf install chromium
Arch Linux / Manjaro
sudo pacman -S chromium
openSUSE
sudo zypper install chromium
Flatpak（通用）
flatpak install flathub org.chromium.Chromium
Snap（通用）
sudo snap install chromium

BSD

使用系统包管理器安装

选择对应的发行版和命令复制到终端执行：

FreeBSD
pkg install chromium
OpenBSD
pkg_add chromium
